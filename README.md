# Etch-a-Sketch
basic java script project 
## features:
- 1. The page contains a drawing board.
- 2. JavaScript creates the grid.
- 3. Each square is a cell that can be colored.
- 4. When I interact with a cell, it changes color.
- 5. The user can choose the grid size.
- 6. The user can choose a drawing color.
- 7. The user can use random color when too lazy to pick a color.
- 8. The user can erase cells.
- 9. The user can clear the entire board.
## What I Learned

- Selecting and manipulating HTML elements using JavaScript
- Creating DOM elements dynamically
- Using loops to generate grid cells
- Using event listeners for user interactions
- Working with input values from a range slider and color picker
- Using functions to organize code
- Managing application state with Boolean variables
